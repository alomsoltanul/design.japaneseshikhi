# jsonfileImages

Drop question images here. Filename must match the question's `image_file`,
e.g. `n5_t1_m1_q1.png`. The app shows them in Studio (question scene), in the
reel video, and on carousel slide 1. Missing image → app falls back to text.

PNG, ideally 4:3 or square, clean and legible at small sizes.
See ../jsonfileLevels/FORMAT.md → "Images" for the recommended AI prompt.
